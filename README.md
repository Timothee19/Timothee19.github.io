# Portfolio — Timothée Soulez Barselo

Portfolio interactif **Apple Glass** (palette **Bleu cuivré & Cuivre brossé sur Carbone**) prêt pour **GitHub Pages** (`Timothee19.github.io`), sans étape de build.

## Points forts
- **Morphing 3D synchronisé dans le Hero** : le nuage de points 3D se métamorphose automatiquement au rythme du texte qui s'écrit (pause ~3s par facette) entre **Agents IA** (graphe d'orchestration), **Deep Learning** (réseau multicouches), **MLOps** (conteneur + boucle CI/CD) et **Quantum** (sphère de Bloch).
- **Visualisations dédiées dans les Projets** :
  - **AnkiCardsGenerator** : pipeline 3D linéaire à 4 agents (*1. OCR → 2. Matière → 3. Découpage → 4. Anki*) manipulable et relançable.
  - **SRGAN** : grille 2D de pixels nets qui se densifie avec un morphing de transition **×1 → ×2 → ×4**.
  - **Autres dépôts publics** : `alzheimer-mri-oasis1`, `Bob-slay` (Parkinson MDS-UPDRS) et `Projet_Churn_Detection` (GitLab).
- **Switch bilingue FR / EN** et CV PDF téléchargeable.
